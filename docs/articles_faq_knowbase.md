## 📖 Article 1 : Comment créer un ticket de support ?

**Catégorie** : Guide Général  
**Mots-clés** : ticket, support, demande, aide  
**Public** : Tous les utilisateurs

### Contenu

**Comment créer un ticket de support dans GLPI UNH**

1. Connectez-vous à GLPI avec vos identifiants universitaires
2. Cliquez sur **Assistance** dans le menu principal
3. Sélectionnez **Créer un ticket** ou cliquez sur **Support Technique**
4. Remplissez le formulaire :
   - **Titre** : décrivez brièvement votre problème
   - **Catégorie** : sélectionnez le type de problème (Matériel, Logiciel, Réseau, etc.)
   - **Description** : expliquez en détail votre problème
   - **Urgence** : indiquez le niveau d'urgence
5. Cliquez sur **Envoyer**

Vous recevrez un email de confirmation avec le numéro de votre ticket.

## 📖 Article 2 : Comment réinitialiser mon mot de passe ?

**Catégorie** : Compte / Accès  
**Mots-clés** : mot de passe, réinitialisation, oublié, accès  
**Public** : Tous les utilisateurs

### Contenu

**Réinitialiser votre mot de passe GLPI**

**Option 1 : Via la page de connexion**
1. Accédez à la page de connexion GLPI
2. Cliquez sur **Mot de passe oublié ?**
3. Entrez votre adresse email universitaire
4. Consultez votre boîte mail et suivez le lien de réinitialisation

**Option 2 : Contactez le support**
Si vous n'avez pas accès à votre email, créez un ticket de support ou contactez directement le service informatique.

**Conseil de sécurité** : Choisissez un mot de passe d'au moins 8 caractères avec des majuscules, minuscules, chiffres et caractères spéciaux.

## 📖 Article 3 : Comment se connecter au WiFi du campus ?

**Catégorie** : Réseau  
**Mots-clés** : wifi, connexion, campus, internet, réseau  
**Public** : Étudiants, Personnel

### Contenu

**Connexion au WiFi UNH**

**Réseau disponible** : `UNH-Campus` ou `UNH-Etudiant`

**Étapes de connexion :**
1. Activez le WiFi sur votre appareil
2. Sélectionnez le réseau `UNH-Campus` (personnel) ou `UNH-Etudiant` (étudiants)
3. Entrez vos identifiants :
   - **Identifiant** : votre matricule universitaire
   - **Mot de passe** : votre mot de passe universitaire
4. Acceptez les conditions d'utilisation si demandé

**Problèmes courants :**
- ❌ "Impossible de se connecter" → Vérifiez que vous êtes dans la zone de couverture
- ❌ "Mot de passe incorrect" → Vérifiez la casse (majuscules/minuscules)
- ❌ Connexion lente → Essayez un autre point d'accès

## 📖 Article 4 : Mon ordinateur ne démarre plus, que faire ?

**Catégorie** : Matériel  
**Mots-clés** : ordinateur, panne, démarrage, écran noir  
**Public** : Tous les utilisateurs

### Contenu

**Mon ordinateur ne démarre pas - Premiers diagnostics**

**Vérifications de base :**
1. ✅ Le câble d'alimentation est-il branché ?
2. ✅ L'écran est-il allumé (voyant lumineux) ?
3. ✅ Avez-vous essayé de maintenir le bouton power 10 secondes ?

**Actions à tenter :**

| Symptôme | Action |
|----------|--------|
| Écran noir total | Vérifiez l'alimentation et le câble écran |
| Ventilateur tourne mais écran noir | Problème de carte graphique possible |
| Bips au démarrage | Notez le nombre de bips pour le technicien |
| Logo puis écran bleu | Problème Windows, contactez le support |

**Si le problème persiste**, créez un ticket en précisant :
- Marque et modèle de l'ordinateur
- Les symptômes exacts
- Les actions déjà tentées

## 📖 Article 5 : Comment installer un logiciel ?

**Catégorie** : Logiciel  
**Mots-clés** : installation, logiciel, programme, application  
**Public** : Étudiants, Personnel

### Contenu

**Installation de logiciels sur les postes UNH**

**Logiciels disponibles sans demande :**
- Microsoft Office (Word, Excel, PowerPoint)
- Navigateurs web (Chrome, Firefox)
- VLC Media Player
- 7-Zip

**Pour installer un logiciel non disponible :**
1. Rendez-vous dans **Assistance > Support Technique**
2. Sélectionnez la catégorie **Logiciel > Installation**
3. Précisez :
   - Le nom exact du logiciel
   - La version souhaitée
   - La raison de la demande (cours, recherche, etc.)

**Note** : L'installation de logiciels non autorisés est interdite pour des raisons de sécurité.

## 📖 Article 6 : L'imprimante ne fonctionne pas

**Catégorie** : Impression  
**Mots-clés** : imprimante, impression, bourrage, papier  
**Public** : Tous les utilisateurs

### Contenu

**Problèmes d'impression - Solutions rapides**

**Vérifications préliminaires :**
1. L'imprimante est-elle allumée (voyant vert) ?
2. Y a-t-il du papier dans le bac ?
3. Voyez-vous un message d'erreur sur l'écran de l'imprimante ?

**Problèmes courants et solutions :**

| Problème | Solution |
|----------|----------|
| "Imprimante hors ligne" | Redémarrez l'imprimante, vérifiez le câble réseau |
| Bourrage papier | Ouvrez le capot, retirez délicatement le papier coincé |
| Impression floue | Remplacez la cartouche (signalez au support) |
| File d'attente bloquée | Annulez les travaux, redémarrez |

**Pour les imprimantes réseau**, vérifiez que vous êtes connecté au bon réseau WiFi.

**Mots-clés** : VPN, distant, télétravail, fichiers, accès  
**Public** : Personnel, Enseignants

**Accès distant aux ressources UNH**

**Option 1 : Portail web**
- Accédez à https://portail.unh.edu
- Connectez-vous avec vos identifiants

**Option 2 : VPN (accès complet)**
1. Téléchargez le client VPN UNH depuis le portail
2. Installez-le sur votre ordinateur personnel

4. Vous avez maintenant accès aux ressources internes

- Serveur : vpn.unh.edu
- Type : SSL/TLS
- Identifiant : votre email universitaire

## 📖 Article 8 : Mon écran reste noir ou figé

**Catégorie** : Matériel  
**Mots-clés** : écran, noir, figé, bloqué  
**Public** : Tous les utilisateurs

### Contenu

**Écran noir ou figé - Que faire ?**

**Si l'écran est complètement noir :**
1. Vérifiez que l'écran est allumé (bouton power)
2. Vérifiez le câble vidéo (HDMI, VGA, DisplayPort)
3. Essayez un autre port vidéo si disponible
4. Testez avec un autre écran si possible

**Si l'écran est figé (ne répond plus) :**
1. Attendez 2-3 minutes (le système peut être occupé)
2. Essayez Ctrl + Alt + Suppr
3. Si rien ne fonctionne, maintenez le bouton power 10 secondes
4. Redémarrez l'ordinateur

**Après un écran bleu (Windows) :**
- Notez le code d'erreur affiché
- Redémarrez en mode sans échec si possible
- Créez un ticket avec le code d'erreur

## 📖 Article 9 : Comment suivre l'état de mon ticket ?

**Catégorie** : Guide Général  
**Mots-clés** : ticket, suivi, état, statut  
**Public** : Tous les utilisateurs

### Contenu

**Suivre l'avancement de votre ticket**

**Via GLPI :**
1. Connectez-vous à GLPI
2. Allez dans **Assistance > Tickets**
3. Cliquez sur votre ticket pour voir les détails

**États possibles :**
| État | Signification |
|------|---------------|
| 🆕 Nouveau | Ticket non encore traité |
| 📋 En cours (attribué) | Un technicien travaille dessus |
| ⏳ En attente | Attente d'information de votre part |
| ✅ Résolu | Solution appliquée, en attente de validation |
| 🔒 Clos | Ticket terminé et archivé |

**Notifications email :**
Vous recevez automatiquement un email à chaque mise à jour de votre ticket.

## 📖 Article 10 : Les raccourcis clavier utiles

**Catégorie** : Guide Général  
**Mots-clés** : raccourci, clavier, productivité, astuces  
**Public** : Tous les utilisateurs

### Contenu

**Raccourcis clavier pour gagner du temps**

**Windows - Essentiels :**
| Raccourci | Action |
|-----------|--------|
| Ctrl + C | Copier |
| Ctrl + V | Coller |
| Ctrl + Z | Annuler |
| Ctrl + S | Enregistrer |
| Alt + Tab | Changer de fenêtre |
| Win + D | Afficher le bureau |
| Win + L | Verrouiller la session |
| Ctrl + Alt + Suppr | Options de sécurité |

**Dans GLPI :**
| Raccourci | Action |
|-----------|--------|
| Alt + B | Accéder à la base de connaissances |
| Alt + T | Créer un ticket |
| Alt + H | Accueil |

**Conseil** : Utilisez Win + L pour verrouiller votre session quand vous quittez votre poste !
